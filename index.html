SaaS · Health clinics

Sonelia

What it does

An online system for clinics (psychology, physiotherapy, medical and aesthetics). Clinics book appointments, keep patient records safe, collect signed consent forms, pay their professionals and remind patients on WhatsApp. Clinics pay a monthly subscription.

How it was built

Multi-tenant SaaS with a React + Vite frontend and a Node.js (Fastify) + MongoDB API. Encrypted medical records with access audit, subscription billing with Mercado Pago and Stripe, 3 languages, light/pink/dark themes and installable as an app (PWA). Runs on Docker in a cloud server.

SaaS · Website monitoring

ServerFall

What it does

It watches websites and servers 24/7 and sends an alert on Telegram when something goes down, so the problem is fixed before customers notice. Each end client gets a page to follow their system and pay the monthly fee.

How it was built

Multi-tenant SaaS with React and a Node.js + MongoDB API. Tracks uptime, CPU/RAM/disk, Docker containers, SSL and domain expiration, logs and a traffic map by country. Payments with Mercado Pago and Stripe, super admin panel with revenue and installable as an app (PWA).

  • React
  • Node.js
  • MongoDB
  • Docker
  • Telegram API
